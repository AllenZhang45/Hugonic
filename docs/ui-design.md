# UI 设计

UI 以单文件原型 [prototype-hugo-desktop-v1.html](prototype/prototype-hugo-desktop-v1.html) 为准（浏览器直接打开）。本文说明布局意图、组件拆分与交互规则。原型中的写死数据与模拟进度不代表最终实现。

## 布局

```
┌────────────────────────────────────────────────────────────────────────┐
│ ● ● ●   H  Hugo Studio   my-blog — Hugo v0.139.0   命令  搜索  部署 ▾   │ 标题栏
├──────┬───────────────────┬─────────────────────────────────────────────┤
│ 图标 │ 资源管理器         │  _index.md ×   hugo.toml ×   single.html ×  │ 标签栏
│ 栏   │ ┌───────────────┐ ├──────────────────────┬──────────────────────┤
│      │ │ 搜索文件…      │ │ Markdown 工具栏       │ 实时预览 localhost:1313│
│ 内容  │ ├───────────────┤ │ 1  +++                │ ┌──────────────────┐ │
│ 面板  │ │ content    12 │ │ 2  title = "…"        │ │  （预览站点内容）  │ │
│ 媒体  │ │  posts        │ │ 3  date = …           │ │                  │ │
│ 主题  │ │  _index.md    │ │ 4  …                  │ │                  │ │
│ 分析  │ │ …             │ │                       │ └──────────────────┘ │
│      │ │ pages/config  │ │                       │                      │
├──────┴───────────────────┴───────────────────────┴──────────────────────┤
│ ● hugo server 运行中  :1313  24 pages  上次构建 0.3s │ main 已同步 UTF-8 Ln 8, Col 12 │
└────────────────────────────────────────────────────────────────────────┘
```

三层结构：**图标栏（功能区）→ 资源管理器（导航）→ 编辑 / 预览分栏（工作区）**，底部状态栏常驻。

## 区域与组件

| 原型区域 | 规划组件 | 说明 |
|---|---|---|
| 标题栏 | `AppTitleBar` | 窗口控制（macOS 风格红绿灯）、应用名、当前项目与 Hugo 版本、命令面板、搜索、部署菜单 |
| 图标栏 | `ActivityBar` | 内容管理 / 仪表盘 / 媒体库 / 主题 / 分析；底部为设置与账户 |
| 资源管理器 | `ExplorerPanel` + `FileTree` | 新建文件、文件搜索、按 Hugo 目录分组的树 |
| 标签栏 | `EditorTabs` | 多文件标签、关闭按钮、脏标记 |
| 编辑器 | `MonacoEditor` | Markdown 工具栏（粗体 / 斜体 / 代码 / 链接 / 图片 / 表格 / Front Matter）、行号、语法高亮 |
| 预览 | `PreviewPane` | 地址条 `localhost:1313`、刷新、外部打开、移动 / 桌面切换，主体为 iframe |
| 状态栏 | `StatusBar` | server 状态、端口、页面数、上次构建耗时、Git 分支、同步状态、编码、光标位置 |
| 构建弹窗 | `BuildModal` | 进度条、流式日志、关闭 / 打开目录 / 重新构建 |
| 部署菜单 | `DeployMenu` | Vercel / Netlify / GitHub Pages / Cloudflare Pages / 导出到本地 |
| 全局提示 | `ToastHost` | 约 1.8 秒自动消失的轻提示 |

## 交互规则

- **打开文件**：单击文件树节点，在标签栏打开（已打开则聚焦），内容载入 Monaco。
- **折叠分区**：点击分组标题切换 `expand_more` / `chevron_right`，不改变当前选中文件。
- **保存**：`Ctrl/Cmd+S` 保存当前标签并清除脏标记；关闭有未保存修改的标签时确认。
- **预览设备**：在移动（约 390px）与桌面（自适应）之间切换容器宽度，不重载 iframe。
- **构建**：工具栏构建按钮或状态栏耗时项打开弹窗；运行中禁用“重新构建”，并提供取消。
- **部署**：标题栏“部署”下拉，点击外部关闭；未配置凭据的平台置灰并给出配置入口。
- **快捷键**：`Ctrl/Cmd+K` 文件搜索、`Ctrl/Cmd+Shift+P` 命令面板、`Ctrl/Cmd+B` / `I` 粗体 / 斜体（编辑器内）。
- **空状态**：未打开项目时工作区显示“打开 Hugo 站点”，隐藏文件树与预览。
- **反馈**：所有操作以 Toast 或状态栏变化回应，避免静默失败。

## 设计 token

来自原型 `:root`，实现时集中放在 `src/styles/tokens.css`，UnoCSS 通过别名引用。

| 类别 | Token | 值 |
|---|---|---|
| 主题 | `--theme-color` | `#6366F1` |
| 主题浅 / 深 | `--theme-light` / `--theme-dark` | `#EEF2FF` / `#4F46E5` |
| 背景 | `--bg-color` / `--bg-secondary` / `--bg-tertiary` | `#0F1117` / `#161822` / `#1E2030` |
| 卡片 | `--card-bg` / hover | `#1E2030` / `#252840` |
| 文本 | primary / secondary / tertiary | `#E2E8F0` / `#94A3B8` / `#64748B` |
| 边框 | `--border-color` | `#2D3148` |
| 状态 | success / warning / error / info | `#22C55E` / `#F59E0B` / `#EF4444` / `#3B82F6` |
| 间距 | xs → xxl | 4 / 8 / 12 / 16 / 24 / 40 px |
| 圆角 | sm / md / lg / full | 6 / 8 / 12 / 50% |

当前只有深色主题。浅色主题是后续项，前提是先把硬编码颜色收敛到语义 token。

## 原型与实现的边界

原型是**静态示意**，以下部分在实现中必须替换为真实能力：

| 原型 | 实际实现 |
|---|---|
| 预览区里的“My Blog”站点 | 真实 `hugo server` 输出，通过 iframe 加载 |
| 随机增长的构建进度 | 由 Hugo 输出驱动，或改为不确定进度条 |
| 写死的构建日志 | 子进程 stdout / stderr 流式转发 |
| 写死的文件树与标签页 | 读取真实项目目录，按需展开 |
| 占位 Toast 文案 | 接入真实操作结果与错误信息 |
