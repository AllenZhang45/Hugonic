## 为什么选择 Hugo
Hugo 是世界上最快的静态站点生成器之一，
基于 Go 语言构建，能够在毫秒级别内
将 Markdown 内容转换为精美的网站。
### 核心优势
- **极速构建**：数千页面仅需几秒
- **灵活模板**：强大的模板引擎
- **零依赖**：单个二进制文件即可运行
- **丰富主题**：数百个开源主题可选
